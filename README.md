## List

`list` — изменяемая упорядоченная коллекция элементов.

Особенности:
- сохраняет порядок;
- можно обращаться к элементам по индексу;
- можно изменять элементы;
- допускает дубликаты.

Пример:

```python
numbers = [1, 2, 3, 4]
print(numbers[0])
```

## Tuple

`tuple` — упорядоченная, но неизменяемая коллекция.

Особенности:
- сохраняет порядок;
- есть доступ по индексу;
- нельзя изменить элементы после создания;
- допускает дубликаты.

Пример:

```python
point = (10, 20)
```

## Dict

`dict` хранит данные в формате `ключ: значение`.

Особенности:
- доступ к данным осуществляется по ключу;
- ключи должны быть уникальными;
- значения могут повторяться.

Пример:

```python
user = {
    "name": "Alex",
    "age": 20
}

print(user["name"])
```

## Set

`set` — коллекция уникальных элементов.

Особенности:
- дубликаты автоматически удаляются;
- элементы уникальны;
- можно выполнять операции над множествами: объединение, пересечение и разность.

Пример:

```python
numbers = {1, 2, 2, 3}
print(numbers)
```

Результат:

```text
{1, 2, 3}
```

## Сравнение структур

| Структура | Изменяемая | Порядок | Дубликаты | Доступ |
|---|---|---|---|---|
| `list` | Да | Да | Да | По индексу |
| `tuple` | Нет | Да | Да | По индексу |
| `dict` | Да | Да | Ключи уникальны | По ключу |
| `set` | Да | Нет фиксированного порядка | Нет | Через операции и `in` |

## List comprehension

List comprehension — короткий способ создать список.

Общий синтаксис:

```python
[выражение for элемент in последовательность if условие]
```

Пример:

```python
numbers = range(1, 11)

even_numbers = [number for number in numbers if number % 2 == 0]
```

Здесь:
- `number ** 2` — выражение;
- `for number in numbers` — цикл;
- `if number % 2 == 0` — необязательное условие.

Comprehension позволяет записать простую операцию со списком компактнее, чем обычный `for`.
